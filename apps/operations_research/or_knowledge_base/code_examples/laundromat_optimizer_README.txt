laundromat_optimizer.py - Pyomo integer programming model for facility planning

Description: This artifact contains a complete Python source code file implementing a Pyomo-based integer programming model for optimizing the equipment mix for a laundromat. It determines the optimal numbers of top-loading and front-loading washing machines to install, subject to practical constraints such as total washing capacity, energy consumption limits, minimum and proportional requirements for each machine type, and other operational restrictions.

Features:
- Formulates a facility planning problem using Pyomo with integer and binary variables. 
- Incorporates constraints on resource use (capacity, energy, machine proportions).
- Suitable as a template for other equipment mix and operations-focused optimization scenarios.
- The code is standalone, includes all major constraints, and is easily modifiable for similar applications in operations research and facility planning.

Typical applications:
- Equipment mix optimization
- Laundromat layout and planning
- Resource-limited integer programming problems
- Educational examples for Pyomo modeling
