# Description: Pyomo Production Planning/Linear Programming Script: paper_lp_solver.py

This Python script provides a complete Pyomo model for a classic production planning/linear programming (LP) problem. It addresses a two-product, resource-constrained scenario common in manufacturing (graph paper and music paper), with an objective to maximize profit and constraints reflecting machine times.

- **Model Details:**
    - Objective: Maximize profit: 4x + 2.5y
    - Constraints:
        - Printing/scanning: 3x + 1.5y <= 350
        - Binding: 5.5x + 3y <= 350
        - x, y >= 0
- **Features:**
    - Fully parameterized Pyomo code, intended as a reusable LP template.
    - Clear, instructive comments and directions for extracting/using results.
    - Robust error handling for missing LP solvers (GLPK, CBC) with user-friendly messages.
- **Solver/Usage Note:** Requires an LP solver compatible with Pyomo. If unavailable, script notifies the user and exits gracefully.

**Purpose/Use Cases:**
- Quickly demonstrate or teach machine/resource-constrained production optimization using LP.
- Serve as example or template for machine allocation in manufacturing research or education.
