# Bakery Production Problem (Resource Allocation Linear Program)

## Summary

A classic operations research problem: maximize profit for a bakery producing bagels and croissants, subject to limited oven and chef hours. The problem is modeled as a linear program (LP) and solved using Pyomo and a standard LP solver.

### Model formulation

Variables:
- x: number of bagel batches (>= 0)
- y: number of croissant batches (>= 0)

Objective:
- Maximize: 20*x + 40*y [profit]

Constraints:
- Oven: 2*x + 1*y <= 70
- Chef: 0.25*x + 2*y <= 32

### Optimal LP (continuous) solution

- Bagels (x): 28.8 batches
- Croissants (y): 12.4 batches
- Maximum profit: 1072.0

### Notes

- Solution assumes batches can be fractional; with integer requirements, use Integer variables.
- Pyomo modeling script saved as: bakery_prod_opt_model.py

## Example application

Resource allocation with two activities/products, two constraints, and profits per activity. Common in manufacturing, service, or scheduling contexts.
